# Historical profile fixtures

- `gson-v7.json` was captured from the onPause draft written by the pre-migration Android APK's GSON writer on an API 36 emulator. It includes Unicode, dormant background values, shader parameters, custom keys, mapping overrides/tombstones and an opaque future controller schema. The baseline source was `6e9f46e7f3d4700897fab8cab2f77f3ce15bc32e` and its locally signed APK SHA-256 was `2779f1be86c219b60c9a5f5cd4886c2d8957ac66e1dec63b6ec94475eb61faec`. An ignored marker was included in the input and verified absent in the captured draft to distinguish an actual writer output from a raw copy.
- `legacy-v2.xml` is a static historical XML input with independently specified expected settings and string-encoded mappings. Android instrumentation also exercises the actual XML parser, v0 property migration and real SparseIntArray behavior.
- `LegacyV7Profile` in JVM tests freezes the old wire declarations. Only its Android SparseIntArray container is represented as a JVM map; real input-map behavior is covered on Android. The old engine is intentionally a test-only dependency for checking the new generated writer. Neither the fixture nor this reader is a production migration model.
