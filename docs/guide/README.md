# User guide

JL-Mod Plus runs Java ME applications and games on Android. These guides cover installation, game organization, customization, and the runtime tools that are less familiar than the original phone-era experience.

The [README](../../README.md) introduces the project. If you have already installed JL-Mod Plus, start with the task you want to complete:

| Guide | Use it when… |
| --- | --- |
| [Getting started](getting-started.md) | You're setting up the app for the first time |
| [Installing MIDlets](installing-midlets.md) | You have a JAR, JAD, KJX, ZIP collection, or folder of games |
| [Library and metadata](library.md) | You want to organize games or change how they appear in the Library |
| [Profiles](profiles.md) | You want to reuse a display or control setup across several games |
| [Appearance and controls](customization.md) | You want to select or manage screen and control skins |
| [Creating screen skins](creating-screen-skins.md) | You're designing a frame around the MIDlet display |
| [Creating virtual-control skins](creating-control-skins.md) | You're making artwork for buttons, the D-pad, or the analog stick |
| [Memory Editor](memory-editor.md) | You need to find or change a value in a running game |
| [Emulation Speed](emulation-speed.md) | You want to slow down or accelerate compatible game timing |
| [Audio and camera](media.md) | You're configuring soundbanks or troubleshooting camera and recording |
| [Troubleshooting](troubleshooting.md) | Something does not install, render, play, or behave as expected |

**About versions:** The guide describes the behavior implemented in the source branch you are reading. A published APK may be older. If your menus differ, check the installed app version before following a troubleshooting instruction.

The [technical documentation](../README.md) covers feature contracts, storage, and Java ME compatibility. For deeper investigations, use the feature guide alongside its technical reference. A guide describes expected behavior; it does not establish the cause of every failure.
