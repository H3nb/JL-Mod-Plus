# JL-Mod Plus

JL-Mod Plus is a fork of [JL-Mod](https://github.com/woesss/JL-Mod).

It runs Java ME applications on Android and provides a Compose Material 3
interface for managing installed applications, Collections, profiles, and
emulator settings. The Java ME runtime retains its native rendering and input
boundaries for compatibility.
